# 🐍 AI Snake - Обучение с подкреплением

Змейка, которая учится играть с помощью Deep Q-Learning (PyTorch).

## 🌐 Демо
[Ссылка на GitHub Pages](https://ваш-username.github.io/snake-ai/)

## 📊 Технологии
- PyTorch (обучение)
- ONNX Runtime Web (инференс в браузере)
- HTML5 Canvas (рендеринг)

## 🎮 Как это работает
1. Модель обучается на Python с использованием DQN
2. Веса экспортируются в ONNX
3. Браузер загружает модель и запускает инференс
4. Визуализация обучения в реальном времени

## 🚀 Запуск локально
```bash
python -m http.server 8000
